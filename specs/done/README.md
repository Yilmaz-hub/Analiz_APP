# specs/done/

Bitmiş (kabul edilmiş ve merge edilmiş) spec'ler buraya taşınır.

- Bir spec'in tüm kabul kriterleri karşılanıp PR squash-merge edilince, dosyası
  `specs/` kökünden buraya taşınır.
- Dosya adı korunur: `NNNN-<ad>.md`.
- Taşımadan önce **SCORECARD** doldurulmuş olmalıdır (bkz. `../TEMPLATE.md`).
- Buradaki spec'ler geçmiş kayıttır; değiştirilmez (düzeltme gerekirse yeni spec açılır).
